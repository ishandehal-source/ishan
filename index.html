Safer homes, connected by an API.

A custom SmartHome Security API that connects locks, cameras, motion sensors, thermostats, mobile clients, and a Packet Tracer data center into one demonstrable security system.

Explore the API ↗See the integration flow
01 · The idea

One service for the home’s most important signals.

The external Flask API returns JSON that can be requested from the Internet-facing Packet Tracer environment, giving the project a clear real-world API interaction to demonstrate.

⌂

Protect entry points

Check lock state, unlock with an authorized code, and lock the home through the application.

◌

See what is happening

Retrieve motion and door-camera events so the system can surface activity instead of isolated device readings.

⌁

Monitor the environment

Read battery levels and temperature data for the thermostat, heater, and air conditioner.

02 · API surface

Everything lives under one simple version.

Use API v1 as the shared base, then choose the short endpoint name that matches the action you need.

API v1 · /api/v1
GET
Devices/devices · Lists every connected smart-home device.
GET
Lock status/lock/status · Shows whether the lock is open or closed.
POST
Unlock/lock/unlock · Opens the door with an authorized code.
POST
Lock/lock/lock · Secures the door through the app.
GET
Motion events/motion/events · Shows recent motion activity.
GET
Camera events/camera/events · Shows recent door-camera activity.
GET
Access codes/access-codes · Lists temporary entry codes.
GET
Battery status/battery/status · Reports connected-device battery levels.
GET
Temperature/temperature · Reports thermostat, heater, and AC data.
